# French Verbs Trainer

Офлайн-тренажёр спряжения французских глаголов для Android.

Приложение адаптировано из Spanish Verbs Trainer: интерфейс, механика квиза и
структура курса сохранены, языковой слой переписан под французскую морфологию.

## Что внутри

- **1418 глаголов** с разметкой группы, вспомогательного глагола и
  орфографических чередований.
- **16 времён** в трёх наклонениях: indicatif, subjonctif, impératif.
- **37 уроков** в восьми блоках с зачётами и мини-тренировками.
- **149 примеров употребления** — живые фразы с русским переводом, по одному
  и более на каждое время.
- Три режима квиза: ввод, выбор варианта, карточки.

## Устройство данных

Спряжения не хранятся, а собираются на лету из модели основ (radicaux):

- `data/verbs.metadata.json` — глагол, перевод, группа, `avoir`/`être`, типы чередований;
- `data/conjugator.ts` — правила групп, семейства третьей группы, согласование причастия;
- `data/irregulars.json` — супплетивные глаголы, задающие основы напрямую;
- `data/lessons.ts` — курс;
- `data/examples.ts` — примеры употребления.

Словарь собирается скриптом: `scripts/generate-verbs.py` берёт частотное ядро и
файл переводов `scripts/translations.fr-ru.txt`, сам выводит группу,
вспомогательный глагол и орфографические типы, и пишет `verbs.metadata.json`.

## Проверки

```
npm run typecheck     # tsc --noEmit
npm run test:data     # инварианты форм, уроков, зачётов и примеров
npm run test:forms    # точная сверка с 36 385 эталонными формами
npm run test:corpus   # покрытие простых времён по корпусу словоформ
npm run gen:verbs     # пересобрать data/verbs.metadata.json
```

Фикстуры в `scripts/fixtures/` — набор эталонных французских словоформ,
снятый для регрессионных проверок генератора.

## Известные ограничения

- Согласование причастия с предшествующим прямым дополнением (`les livres que
  j'ai lus`) не моделируется: оно зависит от порядка слов в предложении, а
  тренажёр работает с изолированными формами.
- Глаголы на `-ayer` даны в варианте с сохранением `y` (`je paye`); написание
  `je paie` тоже нормативно.
- `haïr` пока не включён в словарь — его passé simple требует отдельной
  обработки тремы.
- Примеры употребления написаны для частотных глаголов; у длинного хвоста
  словаря их нет, экран глагола в этом случае просто их не показывает.
