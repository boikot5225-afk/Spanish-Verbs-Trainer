# Spanish Verbs Trainer

Автономный тренажёр испанских глаголов для Android.

## Возможности v1.2

- 2129 испанских глаголов с русскими переводами.
- Поиск по инфинитиву, переводу и спряжённым формам без обязательных ударений.
- 17 времён и наклонений: простые, составные, продолженные, сослагательные и повелительные формы.
- Тренировки с вводом ответа, вариантами и карточками.
- Полностью офлайн.

## Локальный запуск

```bash
npm install
npm start
```

## Проверки

```bash
npm run typecheck
npm run test:data
```

## APK через GitHub Actions

После push workflow **Build Spanish Verbs Trainer APK** собирает установочный APK и прикладывает его к запуску как artifact.
